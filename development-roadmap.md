# FantasyEdge development roadmap

**Development Status: In Progress**

This is a phased plan for proposed development.

### Phase 1: Foundation

Select one sport and scoring format; ingest permitted historical data and implement a baseline projection.

### Phase 2: Core system

Add point-in-time features, a trained model, and rolling backtests with uncertainty reporting.

### Phase 3: Evaluation

Build a constraint-based lineup optimizer and research interface with clear source timestamps.

### Phase 4: Hardening

Improve data refresh, model monitoring, evaluation by segment, and reproducible deployment.
